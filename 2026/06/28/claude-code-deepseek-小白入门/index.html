Windows 从零搭建 Claude Code + DeepSeek 完整指南

2026-06-28 技术分享 Claude Code, DeepSeek, Git, Node.js, 小白入门 评论

目标受众：零基础小白。每一步都配有截图式说明，跟着走就能用上。

一、环境准备

1.1 安装 Node.js

Claude Code 是 npm 包，依赖 Node.js 运行。

  1. 打开 https://nodejs.org → 下载 LTS 版本（长期支持版，最稳定）
  2. 运行安装程序，一路 Next，勾选 “Automatically install the necessary tools”
  3. 验证安装：

如提示 node: command not found，重启终端再试。

1.2 安装 Git

  1. 打开 https://git-scm.com/download/win → 下载 64-bit 版本
  2. 安装时关键选项：
    • Default editor: 选 VS Code（推荐）或 Nano
    • Adjusting your PATH: 选 “Git from the command line and also from 3rd-party software”
    • HTTPS transport backend: 选 “Use the OpenSSL library”
    • Line ending conversions: 选 “Checkout as-is, commit Unix-style”
  3. 验证：

三、接入 DeepSeek API

3.1 获取 DeepSeek API Key

  1. 打开 https://platform.deepseek.com → 注册/登录
  2. 进入 API Keys 页面 → 点击 “创建 API Key”
  3. 复制密钥（只显示一次，保存好）

五、常见问题

5.1 claude: command not found

原因：npm 全局安装目录未加入 PATH。

解决：

Windows 上通常在 C:\Users\你的用户名\AppData\Roaming\npm。

5.2 API 调用报 401/403

DeepSeek 的余额不足、Key 失效、或 ANTHROPIC_BASE_URL 拼写错误。重新获取 Key 或检查环境变量大小写。

5.3 /model 切换模型（cc switch）

Claude Code 交互模式内使用 /model 命令可以切换当前对话使用的模型，相当于 CLI 参数 --model：

如果你配的是 DeepSeek 后端，模型切换能力取决于 DeepSeek 支持哪些兼容模型名。常用的：

命令 对应模型 特点
/model deepseek-chat DeepSeek V3 默认，速度快
/model deepseek-reasoner DeepSeek R1 深度推理，慢但强

也可以设置环境变量指定默认模型：

重启终端后生效，之后每次启动 Claude Code 都会用这个模型。想临时换模型在交互模式用 /model 切就行，不需要改环境变量。

5.4 Claude Code 桌面版绕过登录

桌面版启动后默认强制登录 Anthropic 账号。如果要配合 DeepSeek API，目前没有任何已知方式可以让桌面版跳过认证。因此只能使用 CLI 命令行版本（npm 安装的 claude 命令）。

CLI 版功能与桌面版一致，只是没有 GUI 窗口，在终端里用。VS Code 用户可以安装 Claude Code 插件，插件内置终端面板，体验接近桌面版。

5.5 DeepSeek 支持哪些模型

换成更实用的 /model 命令切 deepseek-chat / deepseek-reasoner。只要不是在对话中途切换（会报错），切换后新对话即生效。CLI 命令行版本是目前唯一可行的方案，桌面版受限于强制 OAuth 登录，无法配合第三方 API 使用。

5.6 速度慢

DeepSeek 免费/低价 API 存在并发限制，高峰期可能排队。用 claude -p "简短问题" 测试延迟。持续卡顿的话考虑充值 DeepSeek 余额提高优先级。

六、日常使用流程

交互模式下，直接打字提问即可，Claude Code 会自动读取当前目录的项目文件作为上下文。

七、环境变量速查表

变量 值 说明
ANTHROPIC_API_KEY sk-xxx DeepSeek API Key
ANTHROPIC_BASE_URL https://api.deepseek.com/v1 DeepSeek API 地址
ANTHROPIC_MODEL deepseek-chat 可选，指定模型

八、总结

步骤 命令
1. 装 Node.js nodejs.org 下载 LTS
2. 装 Git git-scm.com 下载
3. 装 Claude Code npm install -g @anthropic-ai/claude-code
4. 设 DeepSeek Key setx ANTHROPIC_API_KEY "sk-xxx"
5. 设 API 地址 setx ANTHROPIC_BASE_URL "https://api.deepseek.com/v1"
6. 开始使用 claude

全程无需登录 Claude 账号，无需付费 Anthropic API，DeepSeek 注册即用。
